# Face Mask Detection System

## Overview

A real-time Face Mask Detection System developed using Python, TensorFlow, Keras, and OpenCV.

The system detects human faces through a webcam and classifies whether a person is wearing a face mask or not in real time.

## Features

* Real-time webcam detection
* Face detection using OpenCV DNN
* Mask / No Mask classification
* Confidence score display
* Live video stream analysis

## Technologies Used

* Python
* TensorFlow
* Keras
* OpenCV
* NumPy
* Imutils

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```
